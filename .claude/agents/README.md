# Sub-agentes de Claude Code

Esta carpeta contiene 270 agentes especializados instalados desde
[msitarzewski/agency-agents](https://github.com/msitarzewski/agency-agents)
(MIT License), cubriendo ingeniería, diseño, marketing, ventas, producto,
estrategia, testing, seguridad y más.

Se instalaron con el `install.sh` oficial del proyecto (`--tool claude-code`),
sin modificaciones — son una copia directa de los archivos fuente de cada
división (`engineering/`, `design/`, `marketing/`, etc.).

Activa cualquiera durante una sesión de Claude Code pidiéndolo por nombre,
p. ej. *"activa Frontend Developer y ayúdame con..."*.

No tienen relación con el contexto de negocio de LYON (`Harvey/*.md`) — son
herramientas genéricas de desarrollo/diseño/marketing disponibles para usar
al construir sitios para clientes.
