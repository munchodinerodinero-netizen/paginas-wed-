# Máscara LED — Perfiles de Creador (Lote 1)

Generado 2026-08-23 según `references/ugc-creator-engine.md`, elegidos por el ICP real del
producto (Customer Avatar en `01-led-face-mask.md`: mujer 25–45, rutina de skincare básica ya
establecida), no por estética de cámara. Incluye al menos un perfil sin pulir, como exige la
regla de casting del sistema.

## Perfil 1 — Skincare creator (ancla del ángulo curiosidad/contraste)

| Atributo | Detalle |
|---|---|
| Personalidad | Curiosa, analítica con producto, un poco irónica con las tendencias de TikTok |
| Voz | Cercana, ritmo rápido, jerga natural de skincare ("rutina", "step", "glow") |
| Edad aproximada | 27–30 |
| Forma de hablar | Frases cortas, pausas para reacción, poco guion "leído" |
| Estilo visual | Iluminación cálida de cuarto/baño, cámara frontal mano o tripié bajo |
| Ropa | Casual de casa, pijama/bata, sin uniforme de marca |
| Ambiente | Baño o tocador personal, productos de skincare visibles de fondo |
| Tipo de cámara | Cámara frontal de celular |
| Nivel de energía | Medio — natural, no "hype" de anuncio |
| Audiencia | Mujeres 20–35 interesadas en skincare/rutinas |
| Hooks recomendados (`01-led-face-mask-hooks-batch1.md`) | Curiosidad (1–10), Contraste (21–30) |

## Perfil 4 — Wellness/self-care creator (ángulo ritual — prioridad del CEO)

| Atributo | Detalle |
|---|---|
| Personalidad | Tranquila, intencional, habla de "momentos para una misma" sin sonar cursi |
| Voz | Suave, ritmo lento, pausas con propósito (encaja con edición ASMR/satisfying) |
| Edad aproximada | 26–34 |
| Forma de hablar | Casi susurrada en tomas nocturnas, más hablada en tomas de día |
| Estilo visual | Luz cálida tenue, velas o luz de buró de fondo, estética "cozy" |
| Ropa | Bata suave, pijama de buena presentación (sin verse de marca) |
| Ambiente | Recámara de noche, cama tendida, ambiente cuidado pero habitable |
| Tipo de cámara | Celular en tripié bajo, tomas más estables que las demás |
| Nivel de energía | Bajo, calmado — el opuesto a "hype" |
| Audiencia | Mujeres 25–40 interesadas en self-care/wellness, no solo skincare |
| Hooks recomendados | POV (91–98), Sorpresa (31–40), todo el ángulo "ritual nocturno" |

## Recomendación para el primer test ($50/día)

Arrancar con **Perfil 3 (cliente normal) + Perfil 4 (wellness)** — son los extremos del
espectro crudo/pulido. Cruzar el mismo hook con ambos antes de concluir que un hook no
funciona (regla de `references/testing-winner-detection.md`: a veces el problema es el
creador, no el guion). Perfiles 1, 2 y 5 entran en la segunda ronda una vez que haya señal
inicial de qué ángulo y tono conecta más con la audiencia real.
