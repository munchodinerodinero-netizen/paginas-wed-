# Motor UGC — Perfiles de Creador

Antes de escribir un guion, define de qué creador sale. El objetivo es que el video se sienta
contenido nativo de redes sociales — no un comercial de televisión.

## Perfiles base (adaptar edad/tono a la audiencia real del producto)

Mujer 18–24 · Mujer 25–34 · Mujer 35–45 · Hombre · Madre · Profesional · Estudiante · Beauty
creator · Skincare creator · Lifestyle creator · Wellness creator · Pareja · Persona experta
(esteticista, dermo-influencer sin hablar como médico) · Cliente normal (sin estética de
influencer, más creíble para ciertos ángulos).

## Cada perfil necesita, antes de grabarse/escribirse

| Atributo | Ejemplo (perfil: Mujer 25-34, skincare creator) |
|---|---|
| Personalidad | Curiosa, directa, un poco irónica con las tendencias de TikTok |
| Voz | Cercana, ritmo rápido, jerga natural de la plataforma |
| Edad aproximada | 27–30 |
| Forma de hablar | Frases cortas, pausas para reacción, poco guion "leído" |
| Estilo visual | Iluminación cálida de cuarto/baño, cámara frontal mano/tripié bajo |
| Ropa | Casual de casa, sin uniforme de marca |
| Ambiente | Habitación o baño personal, desordenado de forma creíble |
| Tipo de cámara | Cámara frontal de celular, no cámara profesional visible |
| Nivel de energía | Medio — natural, no "hype" de anuncio |
| Tipo de audiencia | Mujeres 20-35 interesadas en skincare/rutinas |

Repite esta tabla para cada perfil que se active en el producto en cuestión — no hace falta
definir los 14 de golpe si el producto solo tiene sentido para 4–5 perfiles reales.

## Regla de casting por producto

- Elegir los perfiles según quién realmente compraría el producto (el ICP), no según qué
  perfiles "se ven mejor en cámara".
- Mezclar al menos un perfil "cliente normal" (sin pulir) por producto — suele generar más
  confianza que el creador demasiado profesional.
- Rotar perfiles entre pruebas: un mismo hook con 2–3 creadores distintos revela si el ganador
  es el guion o la persona.
