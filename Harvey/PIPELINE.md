## Regla de esta tabla

1. Cada fila nueva sale de una prospección real tuya o de un lote que Harvey
   te entregue — nunca se inventa un nombre ni una respuesta.
2. "Interesado" exige una acción del prospecto, no una esperanza tuya.
3. Un "no" se registra igual que un "sí" — es dato para la tasa de cierre,
   no algo que se esconde.
4. Actualiza esto ANTES de pedir el siguiente lote — si no sabes qué pasó
   con los de ayer, no tiene caso sacar más nombres nuevos.
